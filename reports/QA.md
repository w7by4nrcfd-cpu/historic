# ATLAS V1 — التحقق

تاريخ: 12 أكتوبر 2026

## نُفذ ونجح
- 245 تحققًا في Node.js + jsdom، بمحاكاة DOM لا بمتصفح مرئي.
- عرض 58 موضوعًا ومراجعه بلا أخطاء تشغيل DOM، وتحقق جميع IDs والعلاقات والمراجع.
- البحث العربي مع تجاهل التشكيل والهمزات، والنتائج الفارغة.
- الحفظ والإزالة وقراءة الحالة بعد الحفظ، والتخزين التالف أو المحجوب.
- ثلاث رحلات، تسع محطات: الإجابة الخاطئة لا تفتح التقدم، والصحيحة تحفظه.
- فهم أربعة معالم في مخطط بغداد وحفظها.
- سبع لقطات: لكل منها موقع واحد على الأقل؛ طبقة الأحداث تضيف مواقع فعلية ضمن السياق الزمني.
- تحديد الموقع يعرض رابط موضوع، وحدود عنصر الزمن لا تتجاوز اللقطات.
- الانتقال قبل الميلاد وبعده بلا سنة صفر، وعمر المدة عبر الانتقال.
- ثمانية صفوف لدراسة المنافسين، ومراجع في صفحة المنهجية، وصفحة 404 داخل التطبيق.
- node --check للتحقق من تركيب JavaScript.

## إصلاحات نتجت عن التحقق
ضبط معرف الدولة السعودية الأولى، والتوافق بين اللقطات ونطاقات المحتوى، واستبعاد الفقرة المكررة مع المقدمة، وإزالة معلومات الموقع القديمة بعد تبديل الزمن، وفصل تاريخ الحدث عن سنة اللقطة، واستعادة التخزين غير الصالح بأمان.

## لم يُفحص
- عرض بصري فعلي أو لقطات شاشة للواجهة: مهارة control-browser لم تتوفر؛ اتُبعت حدود مسار Sites المُدار ولم يُستخدم متصفح بديل.
- WebGL الحقيقي: محاكاة DOM اختبرت مسار الخريطة البديل والقائمة، لا الرسم المسرع.
- Safari أو iPhone حقيقي، التكبير باللمس، أو قارئ شاشة فعلي.
- مقاييس أداء حية مثل Lighthouse أو Core Web Vitals، والأثر التعليمي على طلاب فعليين.
- تدقيق تاريخي بشري مستقل شامل لجميع المواد.

## التصميم والقابلية للصيانة
CSS متجاوب بثلاث نقاط توقف، RTL، حالات focus، تسميات للأزرار وعناصر الخرائط، وإعداد Reduced Motion. لا توجد تبعيات شبكة لمحتوى التطبيق أو خطه أو خريطته بعد تحميل ملفات الموقع. المصادر الخارجية تفتح كرابط مرجعي. الحفظ محلي فقط.

## إعادة الاختبار
```sh
npm install
npm test
```

الاختبار محاكاة DOM، ولا يجوز تفسير نجاحه باعتباره تحققًا بصريًا أو اختبار Safari.
